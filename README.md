Entry for the [make.fun competition "One Word From Your Ex"](https://make.fun/c/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2): Entrants send exactly one word their ex would use to describe them. The funniest, most painfully honest word takes the whole reward.

## The entry

`main.py` (Python 3, stdlib only, no network) writes the entry (8 characters) to `/output/entry.txt`:

> Roommate

The program is fully deterministic: the same text on every run. It self-checks the length gate before writing it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Files

- `main.py` — the entrypoint; writes the entry to `/output/entry.txt`
- `LICENSE` — MIT
- `.makefun/owner.json` — payout wallet for the entry
